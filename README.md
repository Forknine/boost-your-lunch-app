# Boost Your Lunch App (Expo Starter)

This repository now contains a runnable Expo + React Native starter app that implements the primary BYL screen map as a functional prototype.

## What is included
- Home dashboard with announcement + quick actions
- Order Lunch flow scaffold
- Upcoming Orders list
- Past Orders view
- My Family view
- Support view
- Notifications log view
- Settings view
- Order Detail / Modify screen
- Child Detail / Edit screen

## Run locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start Expo:
   ```bash
   npm run start
   ```
3. Launch on iOS, Android, or web using Expo CLI prompts.

## Notes
- The current version is a UI and navigation scaffold with mock data.
- It is structured so Supabase + Shopify integration can be added next.
